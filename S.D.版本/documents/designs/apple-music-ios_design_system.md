# S.D. 智能财务 · 设计系统 v3（iOS 舒适感取向）

> 提取自参考图（Apple Music Windows 版深色界面）+ iOS 设计原则（Clarity / Deference / Depth）。
> 目标：简洁优先，减少视觉噪音；切换有细致的非线性过渡；图标扁平极简。

## 一、设计原则（来自 iOS 体系）

1. **Clarity 清晰**：文字各字号下可读；图标精确锐利；装饰服从功能。
2. **Deference 谦逊**：UI 帮助用户理解内容但不与之竞争——大面积留白、细分割线代替粗边框、内容才是主角。
3. **Depth 纵深**：通过层级（sidebar → large title → content card）与弹簧动效传达空间感，而非阴影堆砌。
4. **物理感动效**：所有过渡用弹簧曲线（过冲 + 回弹），不用线性 ease——这是「iPhone 舒适感」的核心来源。
5. **即时反馈**：每次点击都有 <100ms 的按压反馈（scale 0.97），每帧都可打断。

## 四、图标系统（重设计：扁平极简）

- 全部改为 **内联 SVG 线性图标**：1.6px 描边、round cap/join、20×20 viewBox 24；
- 不填充、不渐变、不投影；选中态 = accent 色 + 轻微 scale(1.08) 弹簧反馈；
- 图标集：`首页(房子轮廓)` `上传(向上箭头+托盘)` `明细(列表三条线)` `报表(柱状三格)` `连接(对话气泡+勾)` `设置(齿轮简形)` `主题(圆半)`；
- 禁止 emoji 当功能图标（feed 状态点用纯色圆点，不用 ✅⚠️❌ 字符图标；文字回显中允许保留状态字符）。

## 五、组件

| 组件 | 规格 |
|---|---|
| 侧边栏 | 宽 232px；项高 36px，圆角 10px；图标 20px + 文字 14px；选中 = `accent-soft` 底 + accent 色图标文字 |
| 大标题区 | padding 22px 28px 10px；sticky 时缩小为 17px（滚动联动可后置） |
| 卡片 | 圆角 18px；`bg-elevated`；hairline 边框；**无大阴影**（深色下阴影不可见，靠层级） |
| 按钮 | 胶囊形（radius 999）；primary = accent 实底白字；按压 scale(.96) 弹簧回弹 |
| 输入框 | 圆角 10px，hairline 边框，focus 时 accent 2px 外发光（soft 色） |
| 状态徽标 | 胶囊小字（11px/600），soft 底色 + 纯色文字 |
| 弹窗 | 居中卡片，mask blur 12px + 40% 黑；进场 = translateY(28px) scale(.95) → 弹簧归位 |
| 步骤条（连接向导） | 圆点 + 连线，当前步骤 accent 脉冲，完成步骤变 ok 勾 |

## 六、间距系统（4 的倍数）

4 / 8 / 12 / 16 / 20 / 28 / 40。页面左右安全边距 28px；卡片内边距 20px；区块间距 20px；侧边项间距 4px。

## 七、动效规范（非线性）

| 场景 | 曲线 | 时长 |
|---|---|---|
| 页面切换 | `cubic-bezier(.32,.72,.35,1)`（iOS 推入感，无过冲） | 380ms |
| 弹窗进场 | `cubic-bezier(.34,1.56,.64,1)`（弹簧过冲） | 420ms |
| 按钮按压 | `cubic-bezier(.34,1.4,.44,1)` | 200ms |
| 列表项进入 | 弹簧 + 逐级 30ms 延迟（stagger） | 350ms |
| 主题切换 | 线性 ease | 300ms（仅颜色插值） |
| 连接状态脉冲 | ease-in-out 循环 | 1.2s |

规则：位移/缩放用弹簧，透明度可线性；**任何动画 ≤ 500ms**；同时动画元素 ≤ 5 个。

## 八、页面结构（多页 SPA）

```
侧边栏（固定）
 ├── 首页     上传 + 实时动态 feed + 关键 KPI
 ├── 明细     暂存明细表（筛选/复核弹窗/导出）
 ├── 报表     三大报表 tabs + 试算平衡校验
 ├── 连接     微信 ClawBot 状态 + 分步连接向导（含弹窗）
 └── 设置     识别端口/密钥/令牌/用量/日志/危险操作（合并原 admin）
```

- 旧页面向左淡出 + 新页面右侧 24px 滑入（推入方向感）；
- 返回方向反向；同级 tab 用交叉淡入。
